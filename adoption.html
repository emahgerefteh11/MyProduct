Generate, review, and adopt

Unzip the package. With your cloud CLI configured, run these commands from that folder:

python adoption_tool.py discover --manifest candidates.json --output adoption
terraform -chdir=adoption init
python adoption_tool.py plan --directory adoption

AWS: use --aws-profile YOUR_PROFILE for a named profile. GCP: configure gcloud login for discovery and Application Default Credentials for Terraform. Use --engine tofu with OpenTofu.

Review the generated resource definitions and the import plan. The tool blocks plans that change infrastructure. After confirming resources are unmanaged, run:

python adoption_tool.py adopt --directory adoption --confirm-unmanaged

Adoption backs up existing state, applies the reviewed import plan, then checks for a clean plan. Configure your protected remote state backend before shared use. Existing dependency IDs are preserved; dependencies and additional resource types remain visible for follow-up adoption.
